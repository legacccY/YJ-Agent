# NCA-Cyst — 战略叙事（唯一真源）

> 反跑偏主文。任务与本文冲突 → 停下澄清，不照描述硬干。

## Headline（v1，2026-07-08）

> 在 KiTS23 这种「囊肿作为稀疏小类、散布全肾」的多类分割设定下，主流卷积模型对囊肿几乎失效（Dice 0.17–0.45，近随机），根因是**局部感受野看不到全局分布**；我们给参数极小（~13k）的 NCA 补一个**轻量全局视野机制**，在保留 NCA「任意分辨率 + 轻量」卖点的同时，把囊肿分割从近随机拉起来。

**本期（Phase 1）headline 收窄为**：建立 M3D-NCA 与 UNet3D 在 KiTS23 囊肿上的 baseline 对照，验证「主流模型囊肿近随机」在同口径下成立、且 NCA 管线能收敛——为全局视野创新铺可信地基。

---

## 三支柱卖点

1. **痛点真实且有精确边界**：囊肿在多类小散布设定下近随机（文献 + 本期自证 UNet 对照），但**专攻二分类可高分**——故事只在「多类 / 小散布 cyst」成立。
2. **NCA 天生对口 + 有明确缝可补（机制已代码+数据双实测，见 `reference/THEORY_LEDGER.md` H1）**：NCA 参数极小(~13k)、任意分辨率、边缘可跑；但全局视野弱。M3D-NCA 两级存在**结构性两难**——粗级(全局通信发生处)下采样把囊肿抹掉（实测 (64,64,32) 级 9.7% 囊肿完全抹没、中位仅存活 0.4% 体素）；细级在随机 patch 上跑(agent 层不做 mask 优先采样)，囊肿仅 ~0.0065% 体素几乎抽不到、且 patch 间无全局通道。**无一级同时具备「全局视野 + 看得见囊肿」**——散布小囊肿正漏在这。
3. **创新方向蓝海**：全局池化 broadcast / global latent token 是干净空白，最轻、不破坏 NCA 卖点、撞车最低（下阶段）。

> ⚠️ **故事逻辑澄清（措辞红线）**：Phase1 baseline 的 **vanilla M3D-NCA 在囊肿上大概率也失败**——这**不是矛盾，是动机**。「别人跑不了我们能跑」的「我们」= NCA + 全局视野模块(Phase2 创新)，**非** vanilla M3D-NCA。baseline 证「UNet + 原版 NCA 都做不了多类小散布囊肿」，创新模块才是拉起囊肿的东西。写正文务必讲清这层，别让审稿人误读成「你自己的 NCA baseline 也不行，凭什么说 NCA 好」。

## 关键概念厘清（措辞红线，写正文/rebuttal 必守）

- 🔴 **绝不笼统说「囊肿别人都做不了」**。必须限定「KiTS23 多类、囊肿作稀疏小类散布」场景。专攻囊肿二分类 nnUNet 达 0.82–0.90（ADPKD），笼统吹会被一击反驳。
- 🔴 **「全局视野专治 cyst」是文献空白，不能 claim 已被证明**——是我们要用实验填的假设，不是既有结论。
- 🔴 **NCA「全局视野弱」= 公认软肋**（naive NCA 需 ≥100 步才能跨 100×100 图通信），据实陈述，不夸大也不回避。
- 🔴 **baseline 数字诚实**：若 UNet 在囊肿上没那么差，如实报，不为故事硬压对照。
- 🔴 **多 seed 收敛率**，不报单次 Dice（seed 锁不住训练）。

## 对手 / 差异化（related work）

| 对手 | 它做了什么 | 我们的区分 |
|---|---|---|
| M3D-NCA (MICCAI'23) | n-level 多尺度 NCA，全局靠下采样级 | 补高分辨率 patch 间的全局通道（下阶段） |
| FourierDiff-NCA (MECLab) | 频域全局通信 | 避开，改用空域全局池化 broadcast |
| ViTCA / MedSegDiffNCA | attention 补全局 | 更轻量，不引 attention 二次开销 |
| nnUNet | SOTA 卷积，囊肿多类近随机 | 参数少 2 个数量级 + 全局视野 |
