## 1. M3D-NCA 方法 + 官方超参

- **Med-NCA**（MICCAI 2023，arXiv 2302.03473）：每像素=一 cell 持多通道 state（前几维=图+分割输出，其余=隐藏通信通道），所有 cell 共享同一极小 update 网络反复迭代 T 步；参数极小=权重在所有像素+时间步复用。两步：先在 downscaled 粗图跑 NCA 做全局通信，再高分 patch 精分。比 UNet 海马+2%/前列腺+3% Dice，小 500×。
- **M3D-NCA**（MICCAI 2023，arXiv 2309.02954 / ar5iv）：n-level patchification（coarse-to-fine 多尺度）推到 3D；c=16/hidden=64/~12,480 参数；kernel 首层7后续3；步数公式 s=max(W,H,D)/((k-1)/2)；内置质控 NQM（N=10 随机推理用输出方差估可靠度，无需 GT）；能在 Raspberry Pi 4 (2GB) 跑。数据=MSD Hippocampus(198例)+Prostate(32例)。**Dice（%，ar5iv 单源，待核 Table1）**：M3D-NCA 海马90.5/前列腺82.9；nnUNet 91.1/89.2；Med-NCA(2D) 88.1/81.8。
- **官方超参真源**（github.com/MECLabTUDA/M3D-NCA）：Adam(lr=16e-4, betas)、ExponentialLR(gamma=0.9999)。⚠️ **两套示例矛盾**：`train_M3D_NCA.py` = betas(0.5,0.5)/1000ep/步数[10,10]/input[(32,32,26),(64,64,52)]/scale2；`train_M3D_NCA.ipynb`(称"真实数据集") = betas(0.9,0.99)/3000ep/步数[20,40]/input[(80,80,6),(320,320,24)]/scale4。**KiTS23 无官方配置** → input_size/步数/epoch 属适配非复现。
- **NCA 感受野局限**（arXiv 2408.15557）：纯 NCA local update，单步只看邻域，全局靠多步迭代/多尺度慢传；减小模型显著缩小有效感受野。

## 2. 囊肿分割为何难 / 「近随机」的精确边界

- **KiTS 官方把 cyst 列为三类最难**（springer 978-3-031-54806-2_21）："cysts yielded a lower Dice score of 0.447 ... many cysts classified as tumors ... class imbalance"。
- **多类 KiTS23 cyst Dice 极低**：0.447（该参赛论文）；另有报 **17%–20.8%**（arXiv 2312.05528 及参赛论文）。vs kidney 0.93 / tumor 0.69。
- ⚠️ **精确边界（措辞红线）**：专攻囊肿**二分类** nnUNet 可高分——ADPKD CRISP 队列 cyst Dice **0.90±0.05**（pubmed 38389364）；ADPKD 肝囊肿患者级 82%±11%（academic.oup.com/radadv umae014）。→ **动机只在「多类/小散布 cyst」成立，不能笼统说囊肿都做不了**。
- **难点机理**（PMC12733990 DiagNeXt）：小且不规则病灶难检测、类不平衡、cyst-tumor 边界模糊、极端尺寸变异。非增强 CT cyst 与肾实质衰减差异小（arXiv 2405.08282）。

## 3. 给 NCA 加全局视野 prior art（方法蓝海，下阶段）

- **公认软肋**（arXiv 2401.06291）：naive NCA 需 ≥100 步才能跨 100×100 图通信。survey（arXiv 2506.22899 "From Cells to Pixels"）明列为开放问题。
- **已成熟（撞车，headline 避开）**：
  - 多尺度 (b)：Med-NCA/M3D-NCA 本身 + HNCA（github.com/RituPande/hnca）。
  - attention (c)：ViTCA（NeurIPS 2022，arXiv 2211.01233）局部 self-attention 随迭代涌现全局；MedSegDiffNCA（arXiv 2501.02447）CBAM 补全局（皮肤分割）；AdaNCA（NeurIPS 2024，arXiv 2406.08298）。
  - **Fourier (d)：FourierDiff-NCA（arXiv 2401.06291）= M3D-NCA 同实验室 TU Darmstadt MECLab，频域单步全局通信。撞最紧，必避。**
- **蓝海（我们的机会）**：**(a) 全局池化 broadcast** + **(f) global latent/register token**。多源检索均未命中「显式全局池化场耦进 NCA 分割 + 针对散布小目标」直接前作。最轻（参数增量<1k）、不破坏 NCA 任意分辨率+轻量、撞车最低。可借鉴 GNN virtual node（PMC12920779）聚合+广播近似 attention。
- **区分点**：M3D-NCA 全局视野只来自最低分辨率级（下采样换感受野，非真全局聚合）；高分辨率级在随机 patch 上训练、patch 间无全局通道 → 散布小囊肿漏在这。M3D-NCA 论文未做感受野分析、未 claim 解决全局上下文。

## 4. Med-NCA 训练命门（组合台历史复现，Med-NCA伞2026-06-17封存）

来源 `../Med-NCA/Med-NCA复现报告.md`：
- **高分辨率 3D 配置 0/11 全发散**（前列腺 320³+长步数，11 次全中途发散）。
- **静默发散**：loss 死平~5.0(健康~1.25)+Dice=0，但 job 不报 NaN/OOM 跑完。检测器：ep10 后 loss>3 且 Dice<0.05=已死。
- **seed 锁不住**：生死在 epoch1 由 GPU fire-mask RNG + 非确定 kernel 掷定；同 seed 一次收敛一次发散。→ 报多 seed 收敛率。
- **推理步数必须=训练步数**（NCA 非 over-step-stable，过步数崩）。
- **零偏离铁律**：官方 Agent.py 全程无 clip_grad_norm_；连数学等价提速改写（fire-mask CPU→GPU）都毁复现。
- 官方源码 vs 论文两处对不上：感知=固定 Sobel+identity（非可学习）；loss=DiceBCELoss（Med-NCA）/ DiceFocalLoss（M3D-NCA）。
