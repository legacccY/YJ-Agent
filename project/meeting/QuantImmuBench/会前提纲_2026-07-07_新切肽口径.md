## 1. 三条改动逐条解读

### 改动① — 直接用原始 ELISpot 值 rank mutation，不按肽长矫正

- **动作**：撤掉偏相关/残差化控肽长这一层，标签用 raw ELISpot 排序。
- **为什么现在敢不矫正**：不是"放弃严谨"，而是**改动②从源头把混杂拆了，所以①才成立**。①②是一套动作。
- **与余嘉工作的关系**：与余嘉自己的结论同向——余嘉当时落点就是「矫正温和、双口径并报、**不换主口径**」；协作者更进一步「本篇直接 raw、矫正压后」。是**采纳 + 暂缓**，非推翻。
- **资产处置**：矫正深研整套（存在性硬化 + 两层机制 + 矫正菜单 + novelty + 12 页 PPT）→ **就地封存**，不删不改，候选后续独立方法学 note 或本文附录。

### 改动② — 在原始蛋白上滑窗切短肽，且只取包含突变 AA 的肽段（不再切 ELISpot 肽）★最大工程改动

**现状（病根）**：ELISpot 用 15–33mer 长疫苗肽（SLP）；现流程把 SLP 切 9mer 喂工具，`n_subpep` ≈ SLP 长度。**SLP 多长是做疫苗的人人为定的** → 长 SLP 切出更多 9mer → max/top-k pooling 袋子越大越虚高 → **这正是 0.38 肽长混杂的特征侧来源**。

**新做法**：从**原始蛋白序列**围绕突变位点滑窗，**只保留跨过突变 AA 的短肽**。深意：

- 点突变 + 固定窗长 L（如 9mer）→ 跨突变位点的窗口数**恒定 = L 个**（蛋白端部除外），**与 SLP 长度彻底解耦**。
- 袋子大小 → 常数 → pooling 不再随构造长度虚高 → **肽长混杂在特征侧从源头掐死**。
- **用余嘉自己的机制公式验证**：余嘉证过 `控长改动量 Δ ≈ 0.41·ρ_XZ`，工具被污染当且仅当其打分随肽长走（ρ_XZ 大）。**②让所有工具 ρ_XZ→0** → 标签里那 0.38 谁都偷不到 → **无需统计矫正，混杂自然消失**。**这就是①能成立的数学理由。**

**代价**：切肽口径一变，`n_subpep`、pooling、fusion、LOPO、单工具榜——**所有下游数字全部作废重来**；当前 canonical `pooled_clean_9mer.csv` 被替换。

### 改动③ — 同时包含突变肽段 + wild type 肽段（袁老师有现成流程）

- **本质 = 补 DAI**（突变 vs 野生型的差异呈递/免疫原性）。
- **正好接上 R10 卡死点**：R10 特征融合调查当时死在 GT/pooled 表 `含 WT 的列: []`——无 WT 序列/WT 打分 → DAI 全 NaN → L2 层 ≡ L1。
- 袁老师流程给 WT → **最可能有信号的那条腿被接上**，明确利好。

## 2. 明天要谈的问题清单（按重要性）

> 数据现状（Bash 核）：GT 表有 `Vaccine_Peptide`(SLP)、`Short_Epitope`、`Gene_and_Protein_Change`、`Variant_Type`，**无全长蛋白序列、无 WT 序列列**。→ ②③落地都缺数据，这是明天的硬问题。

### A. 数据缺口（先问，卡执行）

1. **②要的"原始蛋白序列"从哪来？** 本地只有 `Gene_and_Protein_Change`（基因+位点），无全长蛋白/转录本序列。是袁老师流程给带侧翼的序列，还是我们按基因拉参考蛋白并定位突变？**这是能不能开工的前提。**
2. **③的 WT 流程输出到什么粒度？** 只给 WT 序列（需我们再过 30 工具打分），还是**连 WT 工具分一起给**？DAI 要"同一工具对 MT/WT 各打一分"，缺 WT 分算不了。

### B. 方法口径（拍死，否则重跑又返工）

3. **滑窗窗长定几？** 只 9mer，还是 8–11mer 全做？（现主口径 9mer，8–11mer pooling 本就是缺口）
4. **indel / 移码突变怎么切？** 点突变跨位点窗口好定；移码后整段是新肽，"包含突变 AA"的定义要说清——DS2 有 28 个 indel，占比不小。
5. **WT 肽只用于算 DAI，还是也进 pooling 袋子？** 直接影响袋子构成与分数。
6. **DAI 用哪种形式？** 相减型 `max(MT−WT,0)` 还是对数比值 `log2(Aff_WT/Aff_MT)`？跟袁老师流程对齐。

### C. 工程与工作量（决定谁做、多久）

7. **需不需要重跑 30 工具？** 新切法会切出**超出原 SLP 范围**的 9mer（尤其短 SLP），工具没打过分 → 大概率要**在新肽集上重跑工具**，非简单重 pool。**这是最大的时间/算力问号，当面估清。**
8. **重跑范围与分工**：切肽 + 重打分归谁（数据组/徐伊琳组/余嘉），下游重出四件套归谁。余嘉本窗能立刻接的是**下游纯 CPU 重算**，上游蛋白序列 + WT 打分依赖别人。

### D. 资产安放（顺带确认，防白做焦虑）

9. 矫正整套（分析 md + 12 页 PPT + 机制公式）**就地封存、留后续/附录，本篇不上**——跟他确认处置，免得后面又被问"矫正呢"。
