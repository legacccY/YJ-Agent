# PPT 质量规格（所有横评 PPT 通用宪法）

> 2026-06-27 立。三类 PPT（新工具 / 10 工具横评 / 5 工具）统一遵守。违反即返工。

## 1. 指标铁律（最重要）
- **Spearman 是头条主指标，不是 AUC。** 强弱「定量」能力 = Spearman，这是项目核心目标。
- 总表第一数据列 = Spearman（rho + 显著性），AUC 放后面作次要参考。
- 结果章先讲 Spearman（能否定量强弱），AUC（能否二分判别）放其后、篇幅更小。
- per-patient Spearman（Fisher-Z）是定量能力的核心呈现。

## 2. 语言（去 AI 味）
- **完整通顺的中文句子，像人写的科普。** 一条信息写成一句话，不是碎词罗列。
- 禁堆砌符号：括号、`·`、`⚠️`、`★`、`→`、`/` 等每页尽量少，能用文字说清就不用符号。
- **禁内部协作术语**（这是对外给袁老师的）：不出现「朱同学」「评判框架」「pooling 专章」「lever」「窗口」「H 窗」等。
  - 「朱同学 pooling 研究」→ 写「子肽聚合方式对评分排序的影响分析」。
  - 客观第三人称，无「我/我们负责」。
- caveman 一律 OFF。

## 3. 图规范（不拉伸 + 标签不干涉）
- **每张图按实际宽高比放容器**，绝不把宽扁图塞进近方容器拉伸。宽扁图（ratio>2）用宽扁容器或重出成 4:3/16:9。
- **柱状图数据标签放在柱子外侧（条形图放条右端外、留白），绝不压在柱子上。** 字号适中、不重叠。
- 横向条形图右侧留足空间放数值标签。
- 暗背景页文字必须用白色/mint 等浅色，保证对比度，绝不深色字压深背景。
- Spearman 主图视觉突出（排序清晰、配色分明）。

## 4. 结构必含章节（仿 5 工具版式）
封面 → 目录 → 项目背景 → 为什么选这些工具（演化光谱 + 文献矩阵）→ 逐工具（工作原理页 + 四类信息页）→ **部署工程（两套战场 + 环境依赖表 + 按工具踩坑问题）** → 数据集来源 → 评测流程 → 看懂指标 → **结果（Spearman 主 + AUC 次）** → 子肽聚合方式分析 → 结论与许可。
