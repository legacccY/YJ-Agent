## 1. DeepHLApan

- 环境类型：Docker → Singularity（conda 路因 keras==2.0.8 + tf==2.7.2 ABI 不兼容放弃）
- 许可：GPL-2.0
- 命令来源：`_hpc_scripts/run_deephlapan.sbatch`

### ① 获取镜像 + 转 Singularity
```bash
# 本地 WSL2 docker
docker pull biopharm/deephlapan:v1.1
docker save biopharm/deephlapan:v1.1 -o deephlapan.tar
gzip deephlapan.tar

# 上传 HPC → singularity build
scp deephlapan.tar.gz zichenli24@hpc.xjtlu.edu.cn:/gpfs/work/bio/zichenli24/tools/
ssh zichenli24@hpc.xjtlu.edu.cn
cd /gpfs/work/bio/zichenli24/tools
gunzip deephlapan.tar.gz
singularity build deephlapan.sif docker-archive://deephlapan.tar
```

### ② 正式跑命令
```bash
# 来源：_hpc_scripts/run_deephlapan.sbatch（Job 1503135）
conda activate deephlapan
deephlapan -F DeepHLApan_dataset2_MT.csv -O outputs/dataset2_MT
deephlapan -F DeepHLApan_dataset2_WT.csv -O outputs/dataset2_WT
```

### ③ 输入构建
- 脚本：`../01_DeepHLApan/`（本地生成 → 上传 HPC）
- HLA 格式：**`HLA-A02:01`**（无星号，与其他工具 `HLA-A*02:01` 不同）

## 5. MHLAPre

- 环境类型：conda（PyTorch 1.12.1+cu102 → CPU 模式跑）
- 许可：开源
- 命令来源：`_hpc_scripts/run_mhlapre.sbatch` + `_build_mhlapre_inputs.py`

### ① clone + 建环境
```bash
cd /gpfs/work/bio/zichenli24/tools
git clone <MHLAPre_repo_url> MHLAPre
module load miniconda3
conda create -y -p /gpfs/work/bio/zichenli24/envs/mhlapre python=3.9
source activate /gpfs/work/bio/zichenli24/envs/mhlapre
pip install torch pandas numpy scikit-learn
```

### ② 输入构建
```bash
# 本地生成 → 上传 HPC
python _build_mhlapre_inputs.py
# 输出：dataset2_MT.csv (29,016 rows)
#       dataset2_WT.csv (22,586 rows)
#       dataset2_MT_predict.csv (25,470 rows)
#       dataset2_WT_predict.csv (20,496 rows)
#       dataset1_MT_predict.csv (321 rows)
#       dataset1_WT_predict.csv (321 rows)
```

### ③ 正式跑命令
```bash
# 来源：_hpc_scripts/run_mhlapre.sbatch（Job 1503158，CPU 模式）
conda activate mhlapre
cd /gpfs/work/bio/zichenli24/tools/MHLAPre
python train_predict.py --mode train --data_dir /gpfs/work/bio/zichenli24/rerun_v2 \
    --output_dir outputs/ --model_dir models/ --epochs 30 --batch_size 128 --device cpu
python train_predict.py --mode predict --data_dir /gpfs/work/bio/zichenli24/rerun_v2 \
    --output_dir outputs/ --model_dir models/ --device cpu
```

### ④ 已知致命坑
- **RTX 4090 CUDA 不兼容**：PyTorch 1.12.1+cu102 仅支持 sm≤75，4090 是 sm_89。解决：`--device cpu`
- **数据泄露**：默认随机切分 train/test 不分患者 → 同患者子肽跨 train/test 分布。修复：GroupKFold by Patient
