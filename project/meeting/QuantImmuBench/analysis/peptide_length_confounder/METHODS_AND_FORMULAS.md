# 存在性森林图·每组处理定义 + 控肽长公式 + 稳健性验算

> 服务 QuantImmuBench 肽长×ELISpot § Part1。所有数字 Bash 独立复算（含从零不 import 引擎的交叉验证，脚本 `_scratch/peplen_existence_robustness.py`）。

## 一、符号与主口径公式

对每位患者 p，记其体内所有疫苗肽的肽长向量 L、ELISpot 向量 E（连续 SFC 斑点数）。

**1. 患者内 Spearman**（先秩化再相关）：把 L、E 各自换成秩 rank(L)、rank(E)，取 Pearson：
```
ρ_p = corr( rank(L_p), rank(E_p) )
```
即"在这位患者体内，肽越长 ELISpot 是否越高"的单调关联强度。

**2. 跨患者 Fisher-z 等权聚合**（把 9 个 ρ_p 合成一个总量）：
```
z_p = arctanh(ρ_p) = ½ ln((1+ρ_p)/(1−ρ_p))      # 方差稳定变换
z̄  = (1/k) Σ z_p                                  # 等权平均(每患者一票, 不因肽多而加权)
ρ̄  = tanh(z̄)                                      # 变回相关尺度 = 主口径 0.380
```
只用患者体内比较、等权平均 → 不跨患者混标签、不被"肽多的患者"主导（对齐大纲 §2.6）。

## 二、控肽长的两种公式（把肽长这个混杂扣掉）

设 X=工具评分（或肽长本身）、Y=ELISpot、Z=肽长（混杂）。

**A. 一阶偏 Spearman（闭式，两侧都扣 Z）**——先秩化，用标准偏相关公式：
```
ρ_{XY·Z} = ( ρ_XY − ρ_XZ · ρ_YZ ) / √( (1−ρ_XZ²)(1−ρ_YZ²) )
```
直觉：从 X↔Y 的相关里，**减去能被 Z 解释的那份** ρ_XZ·ρ_YZ，再归一化。每患者算一个 ρ_{XY·Z,p}，同样 Fisher-z 聚合。患者内需 ≥4 个完整点（比裸相关多耗 1 自由度）。

**B. 残差化（只从标签 Y 扣 Z＝用户原提案）**——最小二乘取残差：
```
在患者 p 内: 用 [1, rank(Z)] 最小二乘拟合 rank(Y), 残差  e_Y = rank(Y) − Ŷ
再算  ρ_p = corr( rank(X), e_Y )                # 只把长度从 ELISpot 里剥掉, 不动工具分 X
```

**C. 多变量联控（一次扣多个混杂 Z₁…Z_m）**——秩残差化：
```
对 rank(X) 与 rank(Y) 各自用 [1, rank(Z₁),…,rank(Z_m)] 最小二乘取残差 e_X, e_Y
ρ_p = corr(e_X, e_Y)                            # 秩空间偏相关, m 个混杂一起扣
```
本文用 Z = {肽长, 子肽数, indel 标记}（robustness）或 {TPM, CCF, 子肽数, indel}（最强联控）。

**显著性两件套**：
- **患者 cluster bootstrap**：有放回重采样 9 位患者 2000 次，每次重算 ρ̄，取 2.5/97.5 百分位 = 95%CI（比固定效应 CI 更诚实，尊重患者是抽样单元）。
- **患者内置换检验**：在每位患者体内打乱 E 与 L 的配对 5000 次，重算 ρ̄ 得零分布，p = 打乱后 |ρ̄| ≥ 实测 的比例。这是**尊重患者聚类**的零分布（比全局打乱更严）。

| 组名（图中标签） | 这组具体做了什么处理 | 数字 |

## 四、稳健性补强实验（新增，保证发现可靠）

| 实验 | 处理 | 结果 | 结论 |
|---|---|---|---|
| 独立复算 | 从零实现、不 import 引擎，重算主口径 | ρ̄=0.3802，与引擎逐位一致 | 交叉验证通过 |
| **LOPO 逐患者留一** | 每次去掉 1 位患者重算 ρ̄ | 区间 [+0.302, +0.422]，9 次全>0（去最强的 P101 仍 +0.302） | **非单患者驱动** |
| **联控全部四混杂** | 偏相关扣 TPM+CCF+子肽数+indel | +0.215，CI[−0.057,+0.466]（k=8） | 点估计仍正，但四混杂同控功效不足、CI 跨 0（小样本代价，非效应消失） |
| **患者内置换检验** | 患者体内打乱 5000 次 | p=0.0004 | 尊重聚类的零分布下高度显著 |
| 符号检验 | 8/9 患者为正，双尾二项 | p=0.039 | 方向一致性显著 |
| per-patient Pearson | 用原值非秩重算主口径 | +0.435 | 比秩相关更强 → 非秩伪迹 |
| 8-11mer 口径 | 换子肽窗口径复现 | +0.380（一致） | 口径无关（肽长按突变恒定） |

**综合**：主口径 0.380 在 独立复算 / LOPO / 患者内置换(p=0.0004) / 符号检验 / Pearson / 换口径 六道检验下全部稳健、方向一致、CI 不过 0。单控与双控（TPM/CCF/子肽数）后 CI 仍不过 0；**唯一的边界是四混杂同控**——点估计仍正 (+0.215) 但 8 患者下功效不足、CI 跨 0（这是小样本同控 4 个协变量的代价，非效应消失，可诚实标注）。存在性队列内可靠（单队列局限见主文档）。
