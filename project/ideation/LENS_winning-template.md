# 制胜模板透镜 · LENS-01：「LLM-Fails → Formalize → SOTA」选题第二引擎

> 建档 2026-07-04。源头 = 拆解 Ruoran Xu（XJTLU 本科）× Qiufeng Wang（PremiLab）的 **Hilbert-Geo（CVPR 2026）**，一个本科生+小组能复制的顶会制胜形状。
> **定位**：`/ideate`（G0-G6）是**减法机器**——它擅长「大量产候选→逐闸杀→只留活得下来的」，但它**没有一个正向造「有希望方向」的引擎**，且它的算力/命门闸会**主动杀掉**方法-理论型题（见 `00_README.md` L124 死活对照 + `STRATEGY_MEMO`）。本透镜补这个洞：**不产 100 个再杀 99，而是照一个已被验证会赢的形状，直接找它的实例。**
> **不复杂**：全程 6 步、一张 checklist、自带一个 $5 的 kill-shot。是 `/ideate` 的**正向前端**，不是替代品——活下来的候选可直接喂 `/ideate` G5 做正式证伪。

---

## 一、制胜公式（一句话）

> **「前沿大模型在某个*可验证*任务上肉眼可见地失败 → 我建那个证明它失败的 benchmark + 一个把它短板补上的*结构化/符号支架* → SOTA 暴涨。」**

「失败的鸿沟」就是论文；「你建的 benchmark」就是护城河；「符号支架」就是方法；「SOTA 数字」就是头条。四件事一次凑齐 = 一篇顶会。

---

## 二、六个槽位（照它填，填满即候选）

| 槽 | 内容 | 判据（怎么算填对） |
|---|---|---|
| **S1 热区** | 一个正在爆发、论文很多的大方向 | MLLM/LLM reasoning、AI4Science、多模态数学/科学推理…（有海量近 1 年顶会论文）|
| **S2 冷角落** | 热区里所有人跳过的一个具体子角落 | 「平面几何做烂了 → 立体几何没人碰」式。人少、但顺着热区叙事一句话能讲通 |
| **S3 可验证任务** | 该角落的任务**有确定、可自动判对错的 ground truth** | ⭐**命门**：答案是精确数/结构/关系（几何答案、计数、空间关系、化学 R/S、逻辑蕴含…），**不是主观/软标签**。没有它整个模板塌 |
| **S4 前沿失败** | frontier 模型（GPT-5/Gemini/Claude）在此任务上**可测地做不到** | 能用 20-30 题在 $5 内验证；失败越惨、鸿沟越大越好（Hilbert-Geo 里 frontier ~50% vs 人类 ~82%）|
| **S5 结构化支架** | 一个**套在冻结 LLM 外面**的形式化/符号/约束/验证层，plausibly 补上失败原因 | 让 LLM 干感知/解析、符号引擎干严格推理与自检（Hilbert-Geo = 形式语言 + 谓词库 + 定理搜索）。**是"支架"不是"新架构/新训练"** |
| **S6 手工可建 + 便宜** | benchmark 小 N（1-3k）可专家标注、无私有数据/湿实验壁垒；全程 API+轻算力 | 2 个标注员 + Kappa 报一下即可；跑=调 API + 符号引擎，**不预训练不要大 GPU** |

加分项（可选，抄 Hilbert-Geo）：**"首个 formalize 这个角落"**（靠 first 拿 novelty）+ **"顺便也能泛化到隔壁"**（多一张表证明通用）+ **批现有 benchmark 的毛病**（数据泄漏/软标签/LLM 生成答案）来给自己正名。

## 三、为什么这个形状特别适合「余嘉 + Claude 单干 / 或进 PremiLab」

正是 `/ideate` 死活对照里 **B 族（benchmark/empirical）全活** 的升级版——但比 quantimmu/ArtiOOD 高一档，因为它**benchmark + 一个能赢的支架**配对（不只是"测别人"，而是"我上去打爆 SOTA"），这一步把它从 D&B-workshop 抬到 CVPR-main：
- **不训练**：API + 符号引擎，8GB 4070 完全够（甚至不用 GPU）。
- **benchmark 手工可建**：Hilbert-Geo 就 2 个本科生标 2k 题。护城河你自己造，不求人、不碰隐私数据。
- **方法=冻结 LLM 外套支架**，不是新架构——工程量在你 2DResMamba/WardLung 的射程内。
- **可验证 GT → 干净 SOTA 数字**：不像医学分割那种软标签要吵指标，答案对就是对。
- **自带最便宜的 kill-shot**（见下）——完美契合组合台"命门最先证伪"纪律。
- **与"进 PremiLab / 王秋峰组"是同一个赌注**：他们组（GNS/Hilbert-Geo）做的就是这个模板。你用这透镜产的方向，正好是能拿去套磁王秋峰、或进组直接开做的题。

⚠️ **命门警告（S3 是阿喀琉斯之踵）**：这套只在**答案可验证**的角落成立。**纯医学影像的软任务（分割好不好、增强像不像）没有确定 GT，套不进来**。要把它用在余嘉的域，必须往**"可验证的科学/医学推理"角落**拐——见第六节。

## 四、轻量流程（6 步，不是 G0-G6）

```
1. 选域      : 一个你能执行、且答案可验证的任务域（S3 优先）
2. 生成      : 照六槽在该域产 10-15 个「热区冷角落 + LLM 失败」候选（一次生成，不搞 100）
3. 筛        : 每个过第五节「有希望」checklist（6 条 yes/no），全 yes 才留
4. Kill-shot : 对存活 top-3 跑自带证伪 —— 花 $5 API 跑 20-30 道该任务的题，
               确认 frontier（GPT-5/Gemini）真失败（★要它失败！失败=头条图；不失败=题死）
5. 撞车快查  : 这个角落真没人 formalize 过？（SPECTER2/Scholar 搜「formal + <角落>」，抄 /ideate G2 逻辑）
6. 收口      : 活下来的 →（a）直接立项开做，或（b）喂 /ideate G5 做正式功效证伪 + G6 拍板
```

**和 `/ideate` 的关系**：本透镜 = 正向"造有希望形状"的**前端**；`/ideate` = 反向"杀脏 claim"的**后端**。第 4 步的 kill-shot 就是 `/ideate` G5「<1GPU·h 命门证伪」在本模板下的化身——只是这里的证伪是**正信号**（你希望模型失败）。两者不冲突，串起来用。

---

## 五、「有希望」checklist（6 条全 yes 才算有希望）

1. **热区冷角落**？——大方向有海量近 1 年顶会论文，但这个**具体角落**人少、没被 formalize。
2. **前沿可测失败**？——GPT-5/Gemini 在此任务上大概率做不到，且能 20-30 题 $5 内验证。
3. **确定可验证 GT**？（⭐命门）——答案是精确数/结构/关系，能自动判对错，**不是主观软标签**。
4. **benchmark 手工可建**？——小 N（≤3k）+ 可专家标注 + 无私有数据/湿实验壁垒。
5. **结构化支架 plausibly 能赢**？——想得出一个套在冻结 LLM 外的形式化/符号/验证层补上失败原因。
6. **全程便宜**？——API + 轻算力，无需大预训练、无需大 GPU。

有一条 no 就降级或换角落。**第 3 条 no = 直接毙**（模板前提塌）。

## 六、给余嘉的 worked example（证明不是空谈，均为候选·未过 kill-shot）

把模板往余嘉**能执行 + 可验证**的角落拐（避开软标签医学影像）。以下每个都填了六槽 + 自带 kill-shot，**都还没跑第 4 步，先别信是金子**：

**候选 A · 医学/解剖的「可验证空间推理」角落**
- S1 热区=医学多模态 MLLM；S2 冷角落=**3D/断层影像里的可验证空间推理**（结构计数、相对位置、层间关系、"A 在 B 的上/内/穿过 B 吗"）；S3 GT=计数/关系有确定答案；S4 失败=MLLM 对 3D 空间关系+计数臭名昭著地差；S5 支架=把解剖空间关系形式化成谓词 + 一个空间关系符号检查器；S6=公开影像手工标 1-2k 题，API 跑。
- Kill-shot：拿 30 道公开 CT/MRI 空间关系题喂 GPT-5/Gemini，若 <60% → 头条有了。
- 契合：正中他医学影像背景 + 可验证，是"医学版 Hilbert-Geo"。

**候选 B · 分子/立体化学的「可验证空间推理」角落**
- S1=科学多模态推理；S2=**立体化学/分子 3D 构型**（手性 R/S、顺反、空间构象判定）；S3 GT=化学有唯一正确答案；S4=MLLM 对分子 3D 手性/构型判定很差；S5 支架=分子图形式语言 + 规则引擎判定；S6=从公开化学题/PubChem 手工建。
- Kill-shot：30 道手性/构型题喂 frontier，看崩不崩。
- 契合：贴他生信底子 + 完全可验证 + 化学-LLM 是热区。

**候选 C · 生物通路图 / 流程图的「结构化推理」角落**
- S1=科学图表理解；S2=**通路图/机制图的可验证问答**（"敲除 X 后 Y 上升还是下降"这类有向图可推的确定答案）；S3 GT=图上可机械推出；S4=MLLM 解析通路图+多步因果推理差；S5 支架=把通路图 parse 成有向作用图 + 符号传播推理；S6=公开 KEGG/通路图手工标。
- Kill-shot：30 道通路推理题喂 frontier。
- 契合：生信 + 可验证 + 图推理支架。

> 三个都命中六槽、都自带 $5 kill-shot。真金与否，**第 4 步跑完才知道**——哪个 frontier 失败最惨、benchmark 最好建，哪个就先做。
